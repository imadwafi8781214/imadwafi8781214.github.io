## Vidéos
GitHub limite chaque fichier à 100 Mo. Pour qu'une miniature ouvre une vidéo, remplis `data-video=""` dans `index.html` :
- lien Instagram / YouTube : `data-video="https://www.instagram.com/reel/..."`
- petit fichier mp4 : `data-video="images/videos/ma-video.mp4"`

## Mettre en ligne (GitHub Pages)
1. Crée un dépôt public sur github.com (ex. `portfolio`).
2. Clique sur **Add file > Upload files**, glisse tout le contenu du dossier (index.html, images, .nojekyll), puis **Commit changes**.
3. **Settings > Pages > Source : Deploy from a branch > main / (root) > Save**.
4. Après 1 à 2 minutes, le site est sur `https://TON-PSEUDO.github.io/portfolio/`.
